# ProjetoAcai: Ganath Açaí

Site de pedidos de açaí para os moradores do condomínio. A pessoa monta o copo (tamanho, frutas e acompanhamentos), vê o açaí sendo montado na tela, coloca na sacola e envia o pedido pronto para o WhatsApp da loja.

- Feito para o celular: o copo fica sempre visível, e as etapas ficam em abas que deslizam
- Sem servidor e sem instalação: é só HTML, CSS e JavaScript
- Preços, horário, número do WhatsApp e formas de pagamento ficam em `js/config.js`

Como editar e publicar: veja o [LEIAME.md](LEIAME.md).
